## Bước A – Lấy mã TV (DUID)

1. **Xem IP máy tính**: mở PowerShell hoặc Command Prompt, gõ `ipconfig`, ghi lại dòng *IPv4 Address* (ví dụ `192.168.1.22`).
2. **Bật Developer Mode trên TV**: mở màn hình **Apps**, bấm trên remote lần lượt các số **1 2 3 4 5** → Developer mode **On** → *Host PC IP* = IP máy tính ở mục 1 → OK. **Tắt hẳn TV rồi bật lại.**
3. **Xem IP của TV**: Cài đặt → Chung → Mạng → Trạng thái mạng → Cài đặt IP.
4. **Lấy mã**: tải `LayID-TV-Samsung.zip` bên dưới, giải nén, bấm đúp **`LAY-ID-TV.bat`**, nhập IP của TV → Enter. Màn hình hiện một dòng mã dạng `BDCLTHZVX36DA`.
5. **Nhắn mã đó** (kèm model TV, ví dụ QA65S95B) cho [@subly_ps](https://t.me/subly_ps).

Không hiện mã: kiểm tra lại Developer Mode đã On và Host PC IP đúng chưa, TV và máy tính có cùng mạng không, TV đã tắt bật lại chưa.

## Bước B – Cài app (sau khi nhận file cài)

1. Giải nén file `SubtitleTV-….zip` nhận được. TV vẫn phải đang bật Developer Mode, cùng mạng với máy tính.
2. Bấm đúp **`CAI-LEN-TV.bat`**, nhập IP của TV. Thấy dòng `install completed` là xong, app **Subtitle TV** tự mở trên TV (lần sau mở từ màn hình Apps).

## Cài đặt trên TV để app chạy ổn (TV đời 2022 trở lên, ví dụ S95B)

| Hiện tượng | Cách xử lý |
|---|---|
| App tự thoát ngay khi hiện hình PS5 | Cài đặt → Tổng quát (và quyền riêng tư) → Trình quản lý thiết bị ngoài → **Anynet+ (HDMI‑CEC) → Tắt**. (TV đổi nguồn theo CEC làm app bị đẩy ra nền.) |
| Hình game trong app bị giật | Đang mở app, bấm Cài đặt → Hình ảnh → Cài đặt chuyên môn → **Cài đặt độ rõ hình ảnh (Auto Motion Plus) → Tắt**. Chỉnh trong lúc app đang hiện hình. |
| Hình game trong app bị mờ / nhạt | Trên PS5: Settings → Screen and Video → Video Output → **HDR → Off**. |

## Dùng hằng ngày

1. Trên máy tính mở Subly, kết nối PS5 và bấm **Bắt đầu**. Cài đặt → iPhone / Web phải đang bật máy chủ web.
2. Trên TV mở **Subtitle TV**: app tự dò máy tính trong mạng, chọn máy rồi OK. Hình PS5 hiện toàn màn hình, phụ đề dịch hiện đè lên.
3. Remote: **⏯** tạm dừng / tiếp tục dịch · **OK** dịch toàn màn hình · **▲▼** dời phụ đề · **◀▶** cỡ chữ · **Kênh ∧** lịch sử phụ đề · **Kênh ∨** xem lại ảnh đã dịch · **Back** mở menu. Số **1–4** chọn cổng HDMI.
