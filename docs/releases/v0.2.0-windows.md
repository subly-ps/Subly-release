> [!CAUTION]
> **Lần đầu mở app**, Windows SmartScreen có thể báo "Windows protected your PC" vì app chưa mua chứng chỉ ký. Bấm **More info → Run anyway**. Nếu Windows hỏi tường lửa (để điện thoại / TV xem phụ đề qua mạng nội bộ), chọn **Private networks → Allow**.

Bản Windows đầu tiên phát hành công khai dưới tên **Subly**, cùng tính năng với bản macOS 0.2.0.

## Có gì trong bản này

- **PS5 Remote (Chiaki)**: nối thẳng tới PS5 qua Remote Play để lấy hình, đăng ký bằng IP + PSN Account ID + mã PIN, hoặc nhập sẵn từ chiaki-ng đã cài trên máy. Nút **Cấu hình** xem lại kết nối đã lưu (IP, MAC, Account ID, khoá đăng ký).
- **Dịch phụ đề thời gian thực**: vẽ khung phụ đề, bấm Bắt đầu, bản dịch hiện đè lên màn hình (overlay) và ghi vào Nhật ký.
- **Nhiều khu vực dịch** trên hình PS5: *Thêm khu vực dịch* rồi kéo chuột quanh vùng chữ khác (bảng chọn, lời nhắc…), bản dịch hiện ngay tại khung đó.
- **Giọng đọc** tiếng Việt: giọng Windows, giọng AI offline (Piper), Microsoft Edge. Mặc định tắt, bật bằng nút loa.
- **Dịch màn hình** (Ctrl+Alt+T): dịch cả bảng nhật ký, tiểu sử, menu và tóm tắt nội dung.
- **Nhân vật, Thuật ngữ** theo từng game, kèm sẵn bộ thuật ngữ cho nhiều game phổ biến.
- **Engine**: Google Translate (miễn phí, không cần key), Gemini (key miễn phí), OpenAI (trả phí). Dịch màn hình mặc định dùng cùng engine với phụ đề.
- **Xem trên điện thoại / TV** qua trang web trong mạng nội bộ; có app **Subtitle TV** cho TV Samsung (xem bản phát hành *Subly 0.2.0 cho Samsung Tizen*).
- Chỉ cho mở một bản app; máy mới dùng được ngay sau khi nhập email.

## Cài đặt nhanh

1. Tải `Subly-0.2.0-Windows.zip` bên dưới, giải nén ra một thư mục bất kỳ (ví dụ `D:\Subly`).
2. Chạy `Subly.exe`. Không cần cài .NET hay gì thêm (đã kèm trong file). SmartScreen chặn thì bấm *More info → Run anyway*.
3. App hỏi email để đăng ký máy, nhập rồi bấm tiếp. Máy được dùng ngay.
4. Kết nối PS5: mở tab **Màn hình → PS5 Remote (Chiaki)**, xem hướng dẫn trong [README](https://github.com/subly-ps/Subly-release#kết-nối-ps5-remote-play--chiaki) (các bước giống bản macOS).

## Yêu cầu

- Windows 10 bản 2004 trở lên hoặc Windows 11, 64-bit.
- Nhận chữ dùng Windows OCR tiếng Anh có sẵn. Nếu app báo *Chưa có OCR tiếng Anh*: Settings → Time & language → Language & region → Add a language → **English (United States)** (tick *Optical character recognition*).
- Giọng AI offline cần Microsoft Visual C++ Redistributable 2015–2022 x64 (máy thường có sẵn).
